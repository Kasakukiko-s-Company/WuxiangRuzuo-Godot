# 资源创作与回接流程

1. 产品/玩法先给资源需求、语义 ID、用途、覆盖状态、画布/时长/格式、锚点、低档回退和验收；未冻结的方向标记为探索，不伪装成正式规格。
2. 在已规划的资源批次中制作适量方向候选或按 brief 指定数量；记录工具、模型/版本、日期、输入参考、提示摘要、人工修改和第三方依赖。
3. 方向、正史或高成本资源由用户明确选择；纯技术变体可按既定规范自动验收。未选择项保持候选，不自动淘汰/融合。
4. 人工重构为可交付源文件，执行原创性、商业许可、相似性、技术规格与平台检查。
5. 源文件/候选放 D 盘 `art-source`/`audio-source`，Godot 运行时成品仅在闸门通过后进入 `assets`。
6. 更新 `ASSET_SOURCES.md`，Godot 4.7.1 生成导入缓存并在目标场景实际验证；不手工伪造 UID/import 文件。

外部素材必须有作者/来源、许可证版本、凭证、修改、署名和审核记录。“免费下载”“网上找到”或“AI 生成”不等于可以商用。禁止商业游戏资源、反编译代码和来源不明素材。

## 当前状态

截至 G2 没有资源达到 Godot 运行时回接闸门。P0 起资源生产是完整游戏正式路线的一部分，不再局限于迁移旧候选；首个批次必须服务 P1/P2 的代表性可玩验证。
