# UI 规格

## 基础

逻辑分辨率 640×360，Control/Container 驱动布局，横屏 `keep` 拉伸。关键信息位于 16:9 安全区，同时通过 PlatformService 叠加 Web/微信安全区。像素 UI 使用整数缩放和清楚焦点，不依赖鼠标悬停。

## 应用 UI 目标

标题：继续、New Game/新游戏、读取游戏、设置；Windows 可有退出，微信不伪造退出。档位界面显示三档状态、日期、地图、保存时间、里程碑和未来恢复点；损坏/不支持/读取失败与空档严格区分。

## HUD 目标

至少显示世界日期、当前目标、八格快捷栏/选槽、交互提示、生命（矿道）、保存反馈。异常/对白期间可降低装饰，但字幕、暂停和退出语义保持可读。

## 输入与无障碍

键盘、手柄和触控共享语义动作；触控按钮不是玩法依赖。提供字幕、音量、reduce motion/镜头移动、画质档。重要状态不能只靠颜色或声音。

## 当前事实

P2 的 `Main.tscn` 已提供 640×360 技术档位页：三个文字可区分的档位、最近游玩标记、空档/日期/地图/保存时间/恢复/损坏/不支持/读取失败状态、所选档启动和默认聚焦“取消”的删除确认。损坏的最近档不会静默跳转，原文件不会在启动时被覆盖；自动布局测试和 Compatibility Renderer 截图已验证内容不越出逻辑视口。

H01 会话已提供 Esc/Start 暂停层：继续游戏与返回标题分开，返回需要第二次确认且默认聚焦“取消”。可写档明确说明返回前会保存当前日期、位置和生活状态，且只有写入成功才导航；写入失败保持暂停确认、显示原因并允许重试。只读恢复明确说明不会保存或覆盖损坏证据。暂停层在场景树暂停时仍可操作，并以同帧最高优先级锁住移动、农作、物资箱和休息等玩法输入。640×360 Compatibility 截图已验证正常页与确认页的层级、焦点和可读性。

这仍不是最终标题界面、设置、HUD 或发行视觉。P2/P3 先验证代表性游戏 UI，P5 固化设计系统与内容管线，P7 前完成全流程 UI；平台安全区、触控和实体手柄矩阵通过后续独立验证。
