# 《雾乡如昨》Demo 范围

## 产品目标

Demo 是可公开试玩、能代表最终气质的原创切片，不以固定时长为目标。它必须证明：平静耕种生活成立；村民具有可建立的关系；玩家主动调查时能遭遇第一处结界异常。固定旧矿道是可选探索/战斗切片，不改变三项核心证明。

## 第一章与四地图

游戏从第一章开始，主角在故乡住宅醒来，只记得从秘境取得神石后昏倒。学院封校、先前真实田园生活、袭击和许愿以后续倒叙揭示，不做传统序章。

四张可独立加载的玩法地图固定为：

1. `home_interior`：醒来、村长首次对白、基础提示、床铺和安全落点。
2. `hometown_main`：农场、住宅外部、村民、关系片段和长期自由生活。
3. `boundary_pass`：北侧道路、第一处“界碑回折”和可忽略线索。
4. `old_mine`：固定单层采矿、基础敌人、生命与安全撤离。

拓扑只有 `home_interior <-> hometown_main <-> boundary_pass`，以及 `hometown_main <-> old_mine`。标题、档位、设置和暂停是应用 UI，不计入地图。地图稳定锚点见 `DEMO_MAP_FLOW.md` 和 `data/demo_world.json`。

## 日常闭环

目标包含四方向移动、碰撞/贴墙滑动、Camera2D、面对格、耕地、播种、浇水、跨天成长、睡觉、收获、背包、八格快捷栏和本地存读档。至少有雾叶草及一种后续确认的辅助原创作物。没有商店、货币或完整经济。

## 人物与关系

Demo 固定 15 名 NPC：4 core、5 support、6 ambient；所有人物有稳定 ID、基础好感和地图存在，但不承诺十五条完整个人线。沈禾承担恋爱可能性预览，宁昭承担友谊/信任预览；Demo 不实现告白、求婚、婚礼或婚后内容。完整规则以 `NPC_BIBLE.md` 为准。

## 第一处异常

`anomaly.first_barrier_fold` 必须由玩家在 `boundary_pass` 面向北、主动确认继续前进后触发。玩家越过旧界碑却再次在前方看见它，并被安全送到 `boundary_return`。返回的路标布可检查也可永久忽略。事件只播放一次，不由日期、睡觉、好感或进图自动触发，不进入不可逆真相期，之后可继续日常。

## 旧矿道切片

完成第一日基础农务后可进入。只含一类矿脉、一种原创矿石、锄镐、学院练习杖、一类基础敌人、5 点生命和安全撤离。生命归零不跨天、不丢物。同日矿脉/遭遇不重复产出，睡觉后重置。没有随机层、Boss、装备成长或完整怪物生态。

## 存档与历法目标

目标为 `profile-1`～`profile-3` 三个独立档位、最近档、损坏隔离、原子写入与未来受保护调查前恢复点。当前 Demo 不创建保护点。世界历法为四季×30 日=120 日/年，开场 `worldDay=1`。天气与日内状态目前只做视觉预设，不是权威玩法。

## 核心真相保密

Demo 不能直接证实军队屠村、三个愿望、愿境本质、重构村民来源、幸存者集体隐瞒或亡灵之地原因。普通敌人也不是死者灵魂、战争残响或愿境守卫。

## 明确不做

最终真相期/Boss/结局、十五人完整个人/婚恋线、随机矿层、经济系统、钓鱼、节日、多人、完整任务系统、云存档、连续时钟、随机天气和超过四图的地图组都不属于当前 Demo。

## Godot 当前实现事实

截至 G1，仅有可启动 Main 场景、工程配置与数据清单。本文件描述的是产品范围，不代表上述玩法已迁移。实现须按 G2～G10 逐阶段验证。
