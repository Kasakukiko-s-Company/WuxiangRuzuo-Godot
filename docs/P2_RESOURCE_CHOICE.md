# P2 H01 每日资源选择切片

## 状态

2026-07-29 已把 H01 北草甸的单一每日赠品改为可运行、可取消、每日互斥的二选一，并与同一物资箱的交换合并为统一行动菜单：

- 雾叶草种子×3：需要后续种植、浇水和跨日成长；按当前目录推导的潜在收获价值为 90。
- 雾叶×1：立即进入背包；当前目录价值为 30。

两项共享稳定领取键 `home.h01.resource.north_meadow.daily_choice`。选择只存在于当前 UI 会话，成功奖励和每日资格由纯领域事务决定；交换行动与领取资格彼此独立。

## 交互与失败语义

1. 面对北草甸资源锚点按 E/A，只打开统一菜单，不发放物品。
2. 当日未领取时显示“种子×3、雾叶×1、出售雾叶、购买种子”四项；已领取时只显示两项交换。
3. Q/Tab 或手柄左右肩键切换；再次按 E/A 确认。打开时自动选中第一项可执行行动。
4. 移动、使用工具、切换数字快捷栏、重置或与其他目标交互会取消待确认菜单。
5. 背包无法完整容纳所选物品时，不增加物品、不记录领取，菜单保持打开，仍可切换另一项或先出售腾出容量。
6. 成功后同组另一来源在当天被领域层拒绝；下一世界日恢复一次选择资格。交易成功不改变这项资格。

## 领域边界

- `DailyResourceSourceDefinition.claim_group_id` 为空时维持原有“一来源一领取键”行为；非空时该组内来源共享领取键。
- `DailyResourceSourceCatalog` 拒绝选择组与普通来源 ID 冲突，也拒绝同组来源指向不同地图或不同语义锚点。
- `DailyResourceGathering` 仍只接受稳定来源 ID；奖励来自受验证目录，领取记录使用来源定义计算出的领取键。
- `DailyResourceClaims` 不知道 UI 和奖励内容，只记录稳定领取键的最近成功世界日。
- `NorthMeadowCrateFlow` 只编排已有 `DailyResourceGathering` 与 `TradeBook`，不会绕过任一领域事务；所有失败保留调用前的 session/claims。
- `SaveSnapshot.schemaVersion=2` 持久化成功领取记录；可取消的“当前选中哪一项”仍是瞬时 UI 状态，不进入存档。退出并重新进入 H01 后，同日已领取资格不会被重置。

## 自动验收

- 领域：同组互斥、次日恢复、组/来源 ID 冲突、锚点不一致、背包满原子失败，以及“种子放不下但雾叶可以放下”的可恢复选择路径。
- 场景：第一次交互只打开、移动取消、再次打开后第二次确认默认种子；交易可在领取前执行且不消耗资格。
- 真实输入：E 打开、Tab 切到雾叶、E 确认；休息到次日后四项行动重新出现并可确认种子；Q/Tab 不会在菜单打开时误改快捷栏，F 仍正常开垦。
- 满背包：两项每日奖励都放不下时自动选中可执行出售；出售后重新打开会选中刚获得容量的雾叶领取。
- 画面：前序 `builds/verification/p2_h01_resource_choice.png` 只证明两项占位界面的 Compatibility 基线，不作为当前四项统一菜单的视觉验收；当前行为由 headless 场景/输入测试覆盖，正式 HUD 仍待后续视觉制作与人工验收。
- 回归：领取记录 schema v2 往返、H01 typed state 恢复和 current/protected 端到端启动已加入自动测试；完整数量以 `PLANS.md` 为准。
