# P2 H01 每日资源选择切片

## 状态

2026-07-29 已把 H01 北草甸的单一每日赠品改为可运行、可取消、每日互斥的二选一：

- 雾叶草种子×3：需要后续种植、浇水和跨日成长；按当前目录推导的潜在收获价值为 90。
- 雾叶×1：立即进入背包；当前目录价值为 30。

两项共享稳定领取键 `home.h01.resource.north_meadow.daily_choice`。选择只存在于当前 UI 会话，成功奖励和每日资格由纯领域事务决定。

## 交互与失败语义

1. 面对北草甸资源锚点按 E/A，只打开候选，不发放物品。
2. Q/Tab 或手柄左右肩键切换候选；再次按 E/A 确认。
3. 移动、使用工具、切换数字快捷栏、重置或与其他目标交互会取消待确认选择。
4. 背包无法完整容纳所选物品时，不增加物品、不记录领取，选择保持打开，仍可切换另一项。
5. 成功后同组另一来源在当天被领域层拒绝；下一世界日恢复一次选择资格。

## 领域边界

- `DailyResourceSourceDefinition.claim_group_id` 为空时维持原有“一来源一领取键”行为；非空时该组内来源共享领取键。
- `DailyResourceSourceCatalog` 拒绝选择组与普通来源 ID 冲突，也拒绝同组来源指向不同地图或不同语义锚点。
- `DailyResourceGathering` 仍只接受稳定来源 ID；奖励来自受验证目录，领取记录使用来源定义计算出的领取键。
- `DailyResourceClaims` 不知道 UI 和奖励内容，只记录稳定领取键的最近成功世界日。
- 没有修改 `SaveSnapshot`、`SaveCodec`、`SaveService` 或存档 Schema；退出场景后选择与领取记录仍会丢失。
