# 《雾乡如昨》旧叙事设定候选（历史参考）

> 本文件是旧原型的创意素材，不再自动构成 Godot 完整游戏正史。主题、真相、人物分类、章节结构和结局必须在 P0 的完整叙事架构中重新评估；正式确认前不得仅因旧文档存在就实现。

> 内部剧透文档。以下核心真相不得在当前 Demo 直接公开。

## 一句话概念

在被战争隔绝的魔法故乡，玩家可长期耕种、交友和恋爱；只有主动追查异常，才会发现“如昨”是由愿望、失去与新生命共同构成的封闭现实。

## 真实时间线

1. 魔法学院因战争无限期封校，主角回乡并重新生活。
2. 主角在秘境取得能实现三个愿望的神石；离乡期间军队袭击并屠杀村庄，多数村民死亡，至少五人幸存。
3. 负责死者归宿的亡灵之地已发生变故，灵魂迅速消散，神石不能真正复生死者。
4. 主角在崩溃中许愿：惩罚袭击者、获得保护他人的力量、让一切恢复原样。
5. 第一愿固定的是暴力/怨恨/死亡的“战争残响”，不是死者灵魂；第二愿把保护扭曲成封闭结界；第三愿依据记忆形成愿境与新的意识。
6. 幸存者留在愿境，为避免主角崩溃和结界失控而隐瞒。主角相关记忆被封印。
7. 第一章从住宅醒来开始。主角记得袭击前的生活和村民，但不知道袭击、许愿与愿境形成。

## 重构村民规则

重构村民不是死者复活、复制品或幻影，而是拥有独立意识的新生命。他们以记忆原型为起点，却会产生新的偏好、冲突、感情与选择。真相线的伦理核心是如何结束诅咒而不再次牺牲这些生命。

## 叙事阶段

1. 表层日常：耕种、关系和长期平静生活成立。
2. 轻微渗漏：记忆、旧物、道路、雾与环境出现可双重解释的矛盾。
3. 主动调查：玩家主动收集证据，气氛逐渐转暗。
4. 最终真相期：只在明确不可逆确认和可靠恢复点后进入。

普通日数、种田、恋爱、睡觉或第一处异常都不会自动进入最终真相期。

## Demo 节拍与揭示边界

住宅醒来 → 第一日日常/关系片段 → 睡觉 → 第二日可选北侧山路 → 玩家主动触发界碑回折 → 可忽略线索并回归生活。旧矿道是独立可选日常分支，不参与异常触发。

Demo 只能让玩家推测边界不正常、部分人可能知道更多；不能证实屠村、愿望、愿境、重构来源、集体隐瞒或最终冲突。

## 一致性护栏

- 主角第一章不是与所有人初见；对白是“主角重逢、玩家初识”。
- 幸存者的隐瞒动机有保护、责任、亲情与分歧，不写成统一神秘表情。
- 重构村民必须表现新选择，不只负责诡异线索。
- 不由儿童或精神不稳定者承担完整真相说明。
- 不可逆调查必须由玩家主动确认并先创建受保护恢复点。
