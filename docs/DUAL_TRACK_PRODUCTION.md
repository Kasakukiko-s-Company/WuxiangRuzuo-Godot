# 主线工程与资源轨并行规则

## 主线工程轨

只修改 Godot 代码、JSON、场景、测试、运行时资源目录和权威文档。主线根据已确认语义 ID/规格预留接口，不顺带生成大量美术/音频。

## 独立资源轨

每个批次只写自己的 `art-source/<batch>` 或 `audio-source/<batch>`，保留候选、原始输出、制作记录、来源/许可和审核导出。用户确认前不得自动定稿、拼接候选或导入 `assets/`。

## 回接闸门

同时满足：用户确认；来源/授权记录完整；人工近似性/质量检查；运行时规格/透明边缘/循环点等通过；文件名和语义 ID 明确；低档回退存在。回接后更新 `ASSET_SOURCES.md` 并运行 Godot 导入/场景验证。

## 所有权与存储

长期源文件、候选、审核导出和运行时资产都在 D 盘。资源任务不能修改玩法/存档/场景逻辑，主线任务也不能自动删除未入围稿。
