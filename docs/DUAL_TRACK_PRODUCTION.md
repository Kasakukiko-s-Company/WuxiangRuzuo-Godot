# 主线工程与资源轨并行规则

## 主线工程轨

负责 Godot 代码、JSON、场景、测试、运行时资源和权威文档。主线必须主动提出玩法所需内容/视听资源 brief，并在已批准的批次内完成集成；不得把资源缺口长期隐藏在占位符后。

## 独立资源轨

内容与资源生产是正式工程轨，可在本项目任务中按批次推进。每个批次只写自己的 `art-source/<batch>`、`audio-source/<batch>` 或明确内容源目录，保留候选、原始输出、制作记录、来源/许可和审核导出。方向或正史尚未确认的候选不得自动定稿或进入运行时 `assets/`。

## 回接闸门

同时满足：方向/内容已批准；来源/授权记录完整；近似性/质量检查；运行时规格/透明边缘/循环点/响度等通过；文件名和语义 ID 明确；低档回退存在。回接后更新 `ASSET_SOURCES.md` 并运行 Godot 导入、目标场景和代表画质验证。

## 所有权与存储

长期源文件、候选、审核导出和运行时资产都在 D 盘。资源与玩法需要通过明确接口共同迭代；跨轨修改必须在同一验收范围中记录。任何任务都不能自动删除未入围稿或未登记来源的唯一副本。
