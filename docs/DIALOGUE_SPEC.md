# 对白规格

## 数据原则

对白使用稳定 `dialogueId` 与本地化文本键；每句显式指定 speaker、portraitId、expressionId、poseId、outfitId、effectId、facing 与回退。程序不能从正文猜情绪或拼不存在的资源路径。

## 叙事语境

第一章是“主角重逢、玩家初识”。角色可自然提及旧称呼/共同习惯，但不能向主角解释双方都知道的关系。旧日熟悉不等于当前好感或恋爱。

## 状态与事务

对白开始时切换输入上下文并抑制世界动作；结束/中断后必定恢复。选择先验证、再一次性提交好感/旗标/物品事务；不得通过表现节点直接修改存档。缺立绘时使用显式 neutral/default 或无立绘回退，不阻塞剧情。

## 边界

未成年人内容保持成年边界；友善/轻微暧昧不自动建立 dating。罗岑山/陈蕴无恋爱对白。Demo 不泄露屠村、三个愿望、愿境、重构来源或集体隐瞒。所有关键音频信息有字幕/旁白替代。
