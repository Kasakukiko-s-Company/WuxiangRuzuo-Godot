# 《雾乡如昨》完整游戏设计框架

本文件描述当前仍值得验证的体验方向，不继承旧 Demo 的内容上限。完整产品定义见 `FULL_GAME_VISION.md`，制作顺序见 `FULL_GAME_ROADMAP.md`。

## 体验支柱

1. 可长期成立的田园日常：劳动、跨天、收获与整理形成安静节奏。
2. 村民是会变化的人：旧日熟悉与当前新生关系并存。
3. 悬疑由玩家主动选择：不调查也能长期生活；调查逐步改变气氛。
4. 有意义的探索与战斗：战斗确定存在，但形态和规模由体验验证决定；区域、采集、谜题、敌人与战斗共同服务成长和叙事，不受固定旧矿道限制，也不默认扩张为高强度动作 RPG。

## 核心循环

当前候选循环为：移动/观察 → 生活生产、交谈或探索 → 管理资源与关系 → 时间推进与世界变化 → 获得新的空间、故事或经营选择 → 继续日常或主动调查。具体农业、经济、制作、建设、任务与战斗深度由垂直切片验证，不机械继承旧功能清单。

## 完整度要求

- 日常循环必须产生长期选择、成长和世界反馈，而不是只重复播种/睡觉。
- 居民、区域、事件和调查需要相互作用，并能覆盖完整游戏流程。
- 开场、教学、成长、中段变化、关键转折、结局和结局后处置必须形成完整旅程。
- 美术、动画、UI、音乐、环境音和音效与系统同步规划，不留到“代码完成后再补”。
- 系统与内容数量以可玩验证、目标时长、质量标杆和制作预算决定。

## 失败与恢复

普通耕种失败应无损、可理解；背包满时事务不吞物品或世界对象。矿道生命归零安全撤离，不跨天、不丢物。损坏存档隔离到单档。未来不可逆真相前必须有受保护恢复点。

## 氛围切换

日常为温暖、清晰的高清像素场景；异常可短暂冷暗、稀疏和微恐，但不依赖高成本效果，并在事件后恢复。画质档只改变表现，不改变规则。

## 当前实现事实

G2 只有启动装配和纯领域基础，不存在上述可玩游戏循环。旧 Demo 与 G3～G10 路线已停止作为产品计划；当前先完成 P0 产品重基线，再按新的体验阶段实施。
